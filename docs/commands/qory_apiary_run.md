## qory apiary run

List runs and read what Qory Apiary recorded about one

### Synopsis

List the runs on Qory Apiary, and read what it recorded about a run, by the run's rn_
id.

  list       list the runs, the last created first
  diagnose   print a run's diagnostics document

More: https://github.com/qoryai/qory/blob/main/docs/apiary.md
