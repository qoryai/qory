## qory harness inspect

Show where every entry of the harness came from

### Synopsis

Print the report of the composed harness: every entry, and the module it came from.

--verbose adds nothing here.

```
qory harness inspect [flags]
```

### Options

```
  -h, --help          help for inspect
      --home string   where the harness is composed: a directory outside the checkout, one home per checkout under it, or .qory/harness (qory.yaml: harness.home)
```
