## qory destination

Clone the destinations of this run

### Synopsis

Clone the destinations of this run: the places that the run's workspace works on, which
the run's inputs list.

--verbose adds nothing here.

More: https://github.com/qoryai/qory/blob/main/docs/run.md#clone-a-destination
